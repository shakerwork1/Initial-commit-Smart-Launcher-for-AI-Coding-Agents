## ✨ Features

- **Beautiful Terminal Interface**: Built using `Rich` and `Questionary` for a modern, dark-themed experience.
- **AI Agent Management**: Launch Claude Code, Codex, DeepSeek, Aider, Cline, and OpenCode seamlessly.
- **Git & GitHub Integration**: Manage repositories, branches, commits, and pushes directly from the UI.
- **Web Analysis Tools**: Run Lighthouse and axe audits with built-in commands.
- **System Diagnostics**: Check for outdated packages and verify tool versions instantly.
- **Automated Setup**: The `.bat` script automatically installs all prerequisites (Python packages, Node.js tools, Claude plugins, and MCP servers) on the first run.

## 🛠️ Tech Stack & Prerequisites

- **OS**: Windows (The `.bat` script is Windows-specific)
- **Languages**: Python 3.8+, Batch Scripting
- **Requirements**: Node.js, npm, Git
